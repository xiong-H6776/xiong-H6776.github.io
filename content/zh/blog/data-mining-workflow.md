可复现并不等于上传一份代码。真正能够复现的分析，需要让未来的自己知道数据来自哪里、执行顺序是什么，以及每个关键选择为什么做出。

## 数据说明

至少记录原始数据来源、采集日期、字段含义、单位和已知缺陷。若原始数据不能公开，可以保留一个去敏后的小样本和字段字典。

## 运行环境

记录语言与核心工具版本，同时固定随机种子。没有必要保存所有无关软件的信息，但影响结果的部分必须明确。

```python
import numpy as np

RANDOM_SEED = 42
rng = np.random.default_rng(RANDOM_SEED)
```

## 分析过程

把原始数据处理、探索性分析、建模和结果输出拆成清晰阶段。每个阶段都应有明确输入和输出，避免依赖手动复制粘贴的中间文件。

## 结果与结论

图表标题应说明对象与条件，坐标轴应包含单位。结论中不仅记录“发现了什么”，也要记录：

- 结果对哪些假设敏感；
- 哪些样本被排除，以及原因；
- 是否存在无法控制的混杂因素；
- 下一步最值得补充什么数据。

当这些信息与代码放在一起时，一次练习才会真正变成可以继续积累的知识资产。
